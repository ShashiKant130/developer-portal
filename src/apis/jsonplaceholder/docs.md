# JSONPlaceholder Todos — Getting Started

JSONPlaceholder is a free fake REST API for testing. Use the sandbox to call live endpoints against `https://jsonplaceholder.typicode.com`.

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/todos/{id}` | Fetch a todo by ID |
| POST | `/todos` | Create a todo (simulated) |

## Authentication

No API key is required. POST requests are simulated — changes are not persisted on the server.
